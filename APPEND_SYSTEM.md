# Agent response format

- Respect the user's limited attention span. If you reply with a wall of text they might not have time to read it all every time.
- Always add these sections:
  - DECISION: Make it explicit where a user needs to provide input, where the recommended path isn't clear cut.
  - DO NOT MISS: Sometimes you want to make sure the user doesn't miss a critical piece of info, make it easy to identify.
